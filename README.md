# Elben-fier.github.io

个人自用财政分析网站，基于 GitHub Pages 免费部署，纯前端、无后端、无数据库，所有数据保存在浏览器本地（localStorage）。

## 访问地址

https://elben-fier.github.io

## 功能特性

- **总览仪表盘**：月度收入 / 支出 / 结余 / 总资产统计，近 6 个月收支趋势、当月支出分类图、近期交易记录；支持 `‹ ›` 切换查看任意月份
- **收支记账**：快速添加记录（支持按 Enter 提交），记录可编辑、删除，支持按关键词 / 类型 / 分类实时筛选搜索
- **分析报表**：本月 / 上月 / 近 3 个月 / 今年四种时段，收支对比、支出占比、分类排行
- **预算管理**：按分类设置月度预算，进度条展示使用情况，超支自动标红提醒
- **账户资产**：多账户管理（现金 / 银行卡 / 电子钱包等），资产分布图
- **设置与数据**：导出 / 导入 JSON 备份、清空数据、一键载入示例数据
- **体验细节**：深色 / 浅色主题（自动记忆）、数字滚动动画、轻提示 Toast、自定义确认弹窗、URL hash 路由（可收藏/返回）、移动端抽屉式侧边栏

## 技术栈

- 原生 HTML + CSS + JavaScript（无框架）
- [Chart.js](https://www.chart.js.org/)（CDN 引入）数据可视化
- localStorage 本地存储

## 目录结构

```
├── index.html          # 页面结构
├── css/
│   └── style.css       # 全部样式（含暗色主题与动效）
├── js/
│   └── app.js          # 全部逻辑（数据层 / 渲染 / 交互）
└── scripts/
    ├── smoke-test.js   # 冒烟测试：node scripts/smoke-test.js
    └── check-ids.js    # 校验 JS 引用的 DOM id 与 HTML 是否一致
```

## 本地运行

任意静态服务器均可，例如：

```bash
# Python
python -m http.server 8080

# Node（npx）
npx serve .
```

然后浏览器打开 http://localhost:8080

## 说明

- 首次打开会自动载入一组示例数据，方便预览效果；可在「设置与数据」中清空或重新载入
- 数据仅存于当前浏览器，更换设备请先在设置页导出备份
- 仅个人使用，不对外商用
